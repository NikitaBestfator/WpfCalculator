# NikBest Calculator

Полноценный калькулятор на WPF с тремя режимами, историей вычислений и чистым интерфейсом.  
Создан в рамках проекта **NikBest Lab** — лаборатории экспериментов в программировании и играх.

---

## 🧮 Функции

- ➕ **Стандартный режим** — базовые операции: сложение, вычитание, умножение, деление.
- 📐 **Инженерный режим** — синусы, косинусы, тангенсы, логарифмы, степени, факториал, константы (π, e).
- 💻 **Режим программиста** — перевод чисел в HEX, BIN, OCT, побитовые операции (AND, OR, XOR, NOT, сдвиги).
- 🕒 **История вычислений** — все действия сохраняются и отображаются в отдельном блоке.
- 🧹 **Очистка истории** — удаление всех записей одной кнопкой.
- ⌨️ **Клавиатурный ввод** — поддерживается ввод с клавиатуры (цифры, операции, Enter, Backspace).
- 🖱️ **Удаление записи двойным кликом** — можно удалить конкретную запись из истории.
