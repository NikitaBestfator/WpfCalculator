# WPF Calculator

Минимальный, но полностью рабочий калькулятор на WPF (.NET).  
Сделан в качестве учебного проекта для изучения основ C# и XAML.

---

##  Функции
- Сложение (+)
- Вычитание (-)
- Умножение (*)
- Деление (/)
- Поддержка десятичных чисел
- Очистка (C)
- Обработка ошибок (деление на ноль)
